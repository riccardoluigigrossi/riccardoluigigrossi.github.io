# Riccardo Grossi — Personal Website

Source for [riccardoluigigrossi.github.io](https://riccardoluigigrossi.github.io).

Single-page static site built with Vite + React. Deployed on GitHub Pages via Actions.

## Development

```bash
npm install
npm run dev        # start dev server at http://localhost:3000
npm run build      # build to ./build
npm run preview    # preview the production build
npm run typecheck  # type-check without emitting
```
